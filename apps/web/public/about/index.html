Free · Open source · Personal by design

A calm place to decide what matters next.

Task-Laureate is a focused task workspace for people who want to turn a busy day into a clear next step. Create lists, add the details that matter, and see honest progress without burying your work in noise.

Try the interactive sampleExplore support

Try before you sign in: the interactive sample workspace uses fictional tasks in this browser tab, never writes to an account, and lets you feel the capture-to-completion flow in under a minute.

Built for focused work

Capture with context

Organise tasks into lists, then add priority, due date, tags, and notes when they help you make a better decision.

See honest progress

Progress views reflect the actual state of your tasks—To do, In progress, completed, blocked, and due—rather than decorative metrics.

Connect related work

Add attachments for reference and connect required task dependencies so the next actionable task stays clear.

Keep control

Use a local workspace or connect a private Supabase project. Export your data whenever you need a portable copy.

Privacy and notifications

Cloud-synced workspaces are account-scoped. Optional daily reminders appear first in a durable in-app inbox; browser alerts are a separate opt-in for each device. Task-Laureate does not present browser push as a substitute for guaranteed real-time delivery.

Open source, ready to adapt

The source is available on GitHub. It is built with React, TypeScript, Vite, and an adapter-based persistence layer so individuals can run and adapt their own workspace. Read the fuller product story and open-source overview on Task-Laureate on GitHub Pages.
