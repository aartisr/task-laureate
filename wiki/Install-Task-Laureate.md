# Install Task-Laureate

Task-Laureate is a Progressive Web App (PWA): users install it directly from
the secure product URL, with no App Store or Play Store account required.

## iPhone and iPad

1. Open [tasks.ai-aarti.com](https://tasks.ai-aarti.com) in **Safari**.
2. Tap the Share button (the square with an upward arrow).
3. Select **Add to Home Screen**.
4. Tap **Add**. The Task-Laureate icon opens like a standalone app.

If the link opened inside another app, choose **Open in Safari** first.

## Android

1. Open [tasks.ai-aarti.com](https://tasks.ai-aarti.com) in Chrome.
2. Tap **Install** in the in-app prompt, or use the browser menu → **Install app**.
3. Launch Task-Laureate from the home screen.

## What installation provides

- One-tap access from the device launcher
- A standalone app window where supported
- Cached app-shell resilience for previously visited screens
- Optional browser-push reminders after explicit permission

For release verification and troubleshooting, use the [PWA release guide](https://github.com/aartisr/task-laureate/blob/master/docs/PWA_RELEASE_AND_INSTALL_GUIDE.md).
