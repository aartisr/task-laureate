# Product Guide

Task-Laureate is designed to reduce uncertainty, not make every task feel
urgent. The shortest useful workflow is below.

## The daily loop

1. **Capture** — save the thought before it becomes a context switch.
2. **Clarify** — add only the detail that makes the next action clear.
3. **Choose** — use **Now** to select work that fits the time and energy you
   actually have.
4. **Do** — make progress without turning the workspace into a second project.
5. **Reflect** — use progress and activity views as evidence, not a verdict.

## Useful places

| Place | Use it for |
| --- | --- |
| **Now** | One feasible action for the current window |
| **Tasks** | Active work, status, due dates, notes, and dependencies |
| **Lists** | Projects and meaningful groupings |
| **Search** | Finding a task, note, or list quickly |
| **Progress** | Honest review of completed and remaining work |
| **Settings** | Sync, privacy, preferences, and browser alerts |

## Planning without pressure

Use dependencies when a task truly cannot start yet. Use a due date only when
it means a calendar day, not as a guilt mechanism. For broad work, create a few
editable child tasks or use the opt-in AI preview; review every suggestion
before accepting it.
