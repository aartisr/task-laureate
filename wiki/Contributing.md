# Contributing

Contributions that improve clarity, accessibility, reliability, privacy, and
focus are welcome.

1. Read [Getting Started](Getting-Started).
2. Make a focused change with tests and documentation where behavior changes.
3. Run `npm run quality:gate`.
4. Open a pull request that explains the user outcome and validation performed.

Do not commit credentials, tokens, private user data, or production exports.
For conventions, start with the repository [README](https://github.com/aartisr/task-laureate#readme)
and [documentation index](https://github.com/aartisr/task-laureate/blob/master/docs/INDEX.md).
